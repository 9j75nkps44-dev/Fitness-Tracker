# FitTrack V1 — Fitness & Nutrition Tracker

FitTrack is a mobile-friendly fitness and nutrition tracker designed as an all-in-one app for tracking food, workouts, progress, and daily goals.

## Features

- Today Dashboard
- Daily calorie tracking
- Protein, carbohydrates, and fat tracking
- Breakfast, lunch, dinner, and snack logs
- Custom food creation
- Water tracking
- Steps tracking
- Workout logging
- Exercises with sets, reps, and weight
- Workout duration and history
- Weight tracking
- Weight progress chart
- Custom daily goals
- Local data storage
- PWA/offline support

## Files

- `index.html` — Main application
- `manifest.webmanifest` — PWA configuration
- `sw.js` — Service worker for offline support
- `README.md` — Project documentation

## How to Run

### GitHub Pages

1. Upload all project files to the GitHub repository.
2. Make sure `index.html` is in the root folder.
3. Go to:

   **Settings → Pages**

4. Select:

   **Deploy from a branch**

5. Select the `main` branch.
6. Select `/ (root)`.
7. Click **Save**.
8. Open the GitHub Pages URL generated by GitHub.

## iPhone / iPad

1. Open the FitTrack URL in Safari.
2. Tap the Share button.
3. Select **Add to Home Screen**.
4. Tap **Add**.
5. Open FitTrack from the Home Screen.

## Data Storage

FitTrack V1 currently uses browser `localStorage`.

Your data is saved locally on the device/browser.

The current version does not yet include:

- User accounts
- Cloud database
- Cloud synchronization
- Multi-device synchronization

## Food Tracking

Users can add food under:

- Breakfast
- Lunch
- Dinner
- Snack

Each food entry can contain:

- Calories
- Protein
- Carbohydrates
- Fat

Users can also create custom foods.

## Workout Tracking

Users can record:

- Workout name
- Workout duration
- Exercise name
- Sets
- Reps
- Weight

Workout history is automatically saved.

## Progress Tracking

Users can log their weight and view:

- Current weight

- Weight change
- Weight trend
